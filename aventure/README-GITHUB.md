# EXPEDITION 2028 — V0.7

## Bibliothèque modulaire

Cette version abandonne le background de bibliothèque composé en une seule image.
La salle est construite à partir de :
- tuiles de sol répétées ;
- modules de murs ;
- sprites PNG transparents indépendants pour le mobilier et les objets ;
- personnages séparés avec tri par profondeur Y ;
- collisions indépendantes des éléments visuels.

### Test
Ouvrir `index.html` via GitHub Pages.

Contrôles :
- ZQSD / flèches : déplacement
- E : interaction
- Entrée / Espace : dialogue suivant
- mobile : joystick + bouton A

La prochaine étape pourra être d'enrichir le tileset et de remplacer progressivement les assets de V0.7 par des assets encore plus détaillés, sans modifier le moteur.
