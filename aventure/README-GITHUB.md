## Upload
Upload the contents of this folder into your `aventure/` folder on GitHub.

No Node, npm, VS Code, Live Server or build step is required.

## Controls
- ZQSD / arrow keys: move
- E: interact
- Enter / Space: advance dialogue
- Mobile: joystick + action button
