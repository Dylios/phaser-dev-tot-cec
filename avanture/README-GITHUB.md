# EXPEDITION 2028 — Prototype Phaser 4 / GitHub Pages

Cette version est conçue pour être utilisée directement dans GitHub Pages.

## Installation

1. Décompresser le ZIP.
2. Ouvrir le dossier `aventure/`.
3. Dans ton dépôt GitHub, ouvrir le dossier où se trouve actuellement ton jeu.
4. Remplacer / ajouter les fichiers du dossier `aventure/`.
5. Commit.
6. Attendre le déploiement GitHub Pages.
7. Recharger avec Ctrl+F5 si le navigateur conserve une ancienne version.

Aucune installation de Node.js, npm, VS Code ou Live Server n'est nécessaire.

Phaser 4.2.1 est chargé depuis jsDelivr dans `index.html`.

## Contrôles

PC:
- Flèches ou ZQSD : déplacement
- E : interaction
- Entrée / Espace : avancer les dialogues

Mobile:
- Joystick : déplacement
- A : interaction
- toucher la boîte de dialogue : avancer

## Important

Cette version est un prototype indépendant. Elle ne contient pas encore toutes les pages / quêtes du moteur précédent.

Objectif de cette étape : valider le rendu, les couches, les collisions, la profondeur et le déplacement avec Phaser avant de migrer définitivement le jeu.
